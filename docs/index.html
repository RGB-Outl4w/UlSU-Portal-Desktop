Как начатьGetting started

Три шага — и портал всегда под рукой.Three steps and the portal is always at hand.

УстановитеInstall

Windows — запустите установщик. Mac — перетащите приложение в «Программы»; при первом запуске разрешите его в «Конфиденциальность и безопасность».Windows: run the installer. Mac: drag the app to Applications; on first launch allow it in Privacy & Security.

Войдите один разSign in once

На настоящей странице портала: логин, пароль и код MAX — как обычно.On the real portal page: login, password and MAX code, as usual.

ПользуйтесьDone

Сессия сохраняется до 30 дней, а приложение может запускаться вместе с системой.The session is kept for up to 30 days, and the app can start when you log in.

Ваши данные остаются у васYour data stays with you

  • Пароль и код MAX вводятся на странице портала — приложение их не видит.Your password and MAX code are entered on the portal's page; the app never sees them.
  • Всё хранится только на вашем компьютере. Своих серверов у приложения нет.Everything is stored only on your computer. The app has no servers of its own.
  • Нет аналитики, телеметрии и рекламы. Связь — только с portal.ulsu.ru (и с GitHub, если вы сами проверяете обновления).No analytics, telemetry or ads. It only talks to portal.ulsu.ru (and GitHub when you check for updates yourself).

FAQ

Частые вопросы.Common questions.

Это официальное приложение УлГУ?Is this an official ULSU app?

Нет. Это независимый проект студента; университет его не создавал и не одобрял. Важное всегда проверяйте на официальном портале.No. It's an independent student project, not made or endorsed by the university. Always check important information on the official portal.

Безопасно ли вводить пароль?Is it safe to enter my password?

Вы вводите его на настоящей странице входа portal.ulsu.ru, открытой в окне приложения. Приложение не читает поля входа и не хранит пароль; сохраняется только cookie сессии портала — так же, как в браузере.You type it on the real portal.ulsu.ru login page shown in the app's window. The app doesn't read the sign-in fields or store your password; only the portal's session cookie is kept, just like in a browser.

Почему не нужно каждый раз вводить код MAX?Why don't I need a MAX code every time?

Браузер удаляет cookie сессии портала при закрытии. Приложение сохраняет его на диске и поддерживает сессию активной, пока работает.Browsers delete the portal's session cookie when they close. The app saves it on disk and keeps the session alive while it runs.

Работает на Mac? А на телефоне?Does it work on a Mac? On a phone?

Да, на Mac с macOS 12 и новее — и на Apple M1–M4, и на Intel. Сборка пока не заверена Apple, поэтому при первом запуске откройте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» (на macOS 12–14 — правый клик по приложению → «Открыть»). Версии для телефонов пока нет.Yes, on Macs with macOS 12 or newer, both Apple M1–M4 and Intel. The build isn't notarized by Apple yet, so on first launch go to System Settings → Privacy & Security → Open Anyway (on macOS 12–14: Control-click the app → Open). There's no phone version yet.

Что-то перестало работатьSomething stopped working

Портал иногда меняется. Создайте issue на GitHub с названием раздела и описанием; не прикладывайте пароли, коды и чужие персональные данные.The portal changes from time to time. Open a GitHub issue with the section name and what you see; never include passwords, codes or other people's personal data.
