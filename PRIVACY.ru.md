# Политика конфиденциальности

**«УлГУ · Портал студента»** · Действует с 12 ноября 2026 г. · [English version](PRIVACY.md)

Коротко: **всё остаётся на вашем устройстве и на самом портале.** Приложение обращается к portal.ulsu.ru, к сайтам, которые вы открываете сами, читает публичную доску объявлений разработчика и номер последней версии на GitHub (и то и другое можно выключить). Разработчик не получает от вас никаких данных.

## Кто отвечает

«УлГУ · Портал студента» — приложение с открытым исходным кодом, созданное студентом как частным лицом (см. [NOTICE.md](NOTICE.md)). У разработчика есть только доска объявлений для приложения, доступная на чтение (см. ниже); он не собирает, не получает и не обрабатывает ваши данные. Данные обрабатываются на вашем устройстве под вашим контролем, а также порталом УлГУ по правилам университета.

## С какими данными работает приложение

| Данные | Откуда | Где хранятся | Зачем |
|---|---|---|---|
| Логин, пароль, код MAX | Вы вводите их на странице входа портала | **Приложение их нигде не хранит.** Они уходят со страницы портала прямо на портал | Для входа. Приложение не читает эти поля |
| Cookie сессии портала (`MoodleSession`) и другие cookie портала | Устанавливает portal.ulsu.ru после входа | Ваш компьютер, папка данных приложения, до 30 дней | Чтобы не входить и не вводить код MAX каждый раз |
| Копии страниц и данных портала (расписание, курсы, оценки, сообщения, профиль, названия ваших личных файлов…) | portal.ulsu.ru | Ваш компьютер, папка данных приложения (`cache`) | Чтобы разделы открывались мгновенно, работали без сети и работал поиск. Поиск читает эти копии; его индекс хранится только в памяти и не сохраняется |
| Презентации, которые вы открываете | portal.ulsu.ru | Ваш компьютер, папка данных приложения (`opened`); на Android — «Загрузки» | Чтобы их открыло системное приложение. «Очистить кэш» и «Выйти» удаляют папку `opened` |
| Журнал сессии (время входа, выхода, потери сессии; без личного содержимого) | Приложение | Ваш компьютер (`session.log`) | Чтобы понять, как долго живёт сессия портала |
| Настройки (тема, язык, акцент, свёрнутая панель, сортировка, вид вкладки «Сегодня») | Вы | Ваш компьютер | Чтобы помнить ваш выбор |
| Фильтр и сортировка курсов | Вы | Собственные настройки портала для вашей учётной записи (те же, что у его «Обзора курсов») | Чтобы приложение и сайт показывали один выбор на всех устройствах |
| Архивные и закреплённые диалоги (и их порядок), диалоги, отмеченные непрочитанными | Вы | Ваш компьютер и небольшой файл `ulportal-sync/sync.json` в ваших личных файлах на портале | Чтобы этот выбор был одинаковым на всех ваших устройствах. Если удалить эту папку на портале, общая копия пропадёт; на каждом устройстве останется своя |
| Файлы, которые вы загружаете или скачиваете | Вы / портал | Выбранная вами папка; загруженные — в ваших личных файлах на портале | Только по вашему действию |

Папка данных приложения: `%APPDATA%\ulportal` в Windows и `~/Library/Application Support/ulportal` в macOS. На Android всё хранится в закрытом хранилище приложения, недоступном другим приложениям; при удалении приложения оно стирается. Фоновая проверка на Android (примерно раз в 15 минут) обращается только к portal.ulsu.ru, а уведомления создаются на самом телефоне.

## Куда отправляются данные

- **portal.ulsu.ru** — все запросы, нужные чтобы показать ваши данные и выполнить подтверждённые вами действия. Это тот же трафик, что и при работе с порталом в браузере.
- **Сайты, которые вы открываете сами**: ссылки на электронные библиотеки (например, Лань, Юрайт, Znanium, IPR SMART, eLIBRARY) открываются в вашем браузере. В этих ссылках есть данные для входа, которые формирует для вас портал. Что делают эти сайты, определяется их собственными политиками.
- **Boosty — только если вы нажмёте.** Необязательная кнопка **«Поддержать проект»** открывает boosty.to в вашем браузере, без сессии портала. Само приложение к Boosty не обращается; там действует политика Boosty.
- **GitHub — проверка обновлений.** Каждые 6 часов, пока приложение работает, и по кнопке **«Проверить обновления»** в разделе «О приложении» приложение отправляет один запрос к api.github.com, чтобы узнать номер последней версии. В запросе есть только версия приложения (в User-Agent), без личных данных. Если вышла новая версия, приложение сообщает об этом и даёт ссылку на страницу выпуска; само оно ничего не скачивает и не устанавливает. **Настройки → Обновления → Только по кнопке** оставляет проверку только по кнопке.
- **Объявления разработчика (Supabase).** При запуске, раз в час и при возврате в приложение (не чаще раза в 15 минут) приложение читает список текущих объявлений (например, «портал изменился, обновите приложение») из проекта разработчика в Supabase (supabase.co, регион ЕС). Это только чтение: без личных данных, без данных портала и без идентификаторов. Список фильтруется по версии и платформе на вашем устройстве. Как и любой веб-запрос, он сообщает Supabase ваш IP-адрес; там действует политика Supabase. **Настройки → Объявления разработчика → Не проверять** выключает проверку.
- **Больше никуда.** Нет аналитики, отслеживания, телеметрии, отчётов о сбоях и рекламы.

## Уведомления

Пока приложение работает (в том числе из трея или строки меню), оно раз в несколько минут проверяет на портале новые уведомления и сообщения. Текст уведомления показывает операционная система на вашем компьютере; никуда больше он не отправляется.

## Удаление данных

- **Настройки → Выйти из аккаунта** завершает сессию на портале и удаляет сохранённые cookie и копии данных.
- **О приложении → Очистить кэш** удаляет сохранённые копии, но оставляет вас в системе.
- Чтобы удалить всё, удалите приложение и папку данных (см. выше).

Данные на самом портале (учётная запись, сообщения, файлы, заявки) находятся под управлением университета, а не этого приложения.

## 152-ФЗ «О персональных данных»

Разработчик приложения не получает и не обрабатывает ваши персональные данные: обработка происходит на вашем устройстве по вашей инициативе, а также на портале университета по правилам университета. Поэтому разработчик не является оператором персональных данных в отношении этого приложения.

## Дети

Приложение предназначено для студентов и сотрудников УлГУ и ни у кого целенаправленно данных не собирает.

## Изменения

Изменения политики публикуются в репозитории проекта с обновлённой датой выше. Вся история изменений видна в репозитории.
