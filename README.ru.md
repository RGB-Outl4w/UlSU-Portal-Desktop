## Зачем

Портал выходит из учётной записи каждый раз, когда закрывается браузер, а повторный вход — это снова ожидание кода MAX. «УлГУ · Портал студента» хранит сессию на вашем компьютере, поэтому входить нужно один раз. А ещё приложение даёт быстрый и удобный интерфейс поверх портала.

## Возможности

| | |
|---|---|
| **Сегодня** | Баннер «идёт сейчас / следующая пара», пары на сегодня, ближайшие дедлайны, свежие уведомления, задолженности |

| **Курсы** | Курс открывается в приложении: разделы, отметки о выполнении, галерея материалов, просмотр PDF, участники, избранное |
| **Дедлайны и оценки** | Предстоящие и просроченные задания; оценки с сортировкой и фильтрами |
| **Успеваемость** | Оценки по семестрам со средним баллом и полный учебный план с часами и рабочими программами |
| **Уведомления и сообщения** | Панель чтения, чаты, отправка сообщений, счётчики непрочитанного, уведомления Windows |
| **Сервисы** | Заказ справок, вопросы университету, личные файлы (загрузка и скачивание), вход в электронные библиотеки |
| **Без сети** | Каждый открытый раздел сохраняется и работает без подключения |
| **Удобство** | Светлая и тёмная тема, цвет акцента, русский и английский, поиск по Ctrl+K, горячие клавиши, режим уменьшения анимации |

## Установка

> Windows 10/11. Установщики будут на странице [Releases](https://github.com/RGB-Outl4w/UlSU-Portal-Desktop/releases).

### Запуск из исходников

```bash
git clone https://github.com/RGB-Outl4w/UlSU-Portal-Desktop.git
cd UlSU-Portal-Desktop
npm install
npm start
```

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

## Как это работает

- **Вход.** Приложение открывает настоящую страницу входа портала в своём окне. Логин, пароль и код MAX вы вводите там; приложение эти поля не читает.
- **Сессия не теряется.** Cookie сессии портала удаляется при закрытии браузера. Приложение сохраняет его на диске до 30 дней и раз в несколько минут поддерживает сессию, пока работает (в том числе из трея).
- **Данные.** Публичного API у портала нет, поэтому приложение использует те же запросы, что и сам сайт, а некоторые страницы (расписание, успеваемость, учебный план) читает напрямую.
- **Скорость и работа без сети.** Каждый раздел сразу показывает сохранённую копию, а затем незаметно обновляется из сети.

## Конфиденциальность

Все данные остаются на вашем компьютере. Нет аналитики, телеметрии и собственных серверов. Приложение обращается только к portal.ulsu.ru и к сайтам, которые вы открываете сами. Подробнее — в [Политике конфиденциальности](PRIVACY.ru.md).

## Отказ от ответственности

Это **неофициальный** проект. Он не создан, не одобрен и не поддерживается Ульяновским государственным университетом. Названия «УлГУ» и «ULSU» используются только чтобы указать, с каким сайтом работает приложение. Важную информацию всегда проверяйте на официальном портале. См. [NOTICE.md](NOTICE.md#русский).

## Структура проекта

```
main.js        Главный процесс Electron: сессия, сеть, кэш на диске, трей, уведомления
preload.js     Небольшой API, доступный окну (window.portal)
app.js         Интерфейс: разделы, разбор страниц портала, навигация
i18n.js        Английские строки (интерфейс написан на русском)
index.html     Разметка окна, иконки, диалоги
app.css        Токены дизайна, раскладка, анимации
offline.html   Страница для окон портала при отсутствии сети
docs/          Сайт проекта (GitHub Pages)
```

Заметки о разработке и этапы — в [ROADMAP.md](ROADMAP.md).
